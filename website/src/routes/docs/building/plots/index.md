## Choose a plot

In an available plot world, `/plot auto` finds and claims an eligible plot; `/plot claim` claims the plot you are standing in when available. Limits depend on your access. Use `/plot info` to inspect ownership and `/plot home` to return to your plot.

These commands apply to designated plot areas. They do not reserve arbitrary survival land; use a [golden-shovel claim](/docs/protection/land-claims/) there.

## Invite builders

`/plot add <player>` allows a helper while you are online. `/plot trust <player>` gives broader building access, including while you are offline. Use `/plot remove <player>` to remove a helper's access when the project ends.

Choose the smallest grant that fits your collaboration. Do not add a public building grant just to invite one friend.

## Inspect before changing

Plot rules and available flags vary. Read the current command help rather than assuming every plot command is unlocked. Clearing, deleting, or disposing a plot can remove work or protection; inspect its ownership and contents before confirming any destructive action.

Inventories can differ between creative and survival worlds. See [world travel](/docs/travel/portals-and-worlds/) before carrying valuable supplies through a portal.
