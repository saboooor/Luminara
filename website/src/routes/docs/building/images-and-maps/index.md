## Plan the wall

Choose an image you are allowed to display and a wall in an area you can build. Dimensions are measured in maps: a 2 by 2 display needs space for four map tiles and their item frames.

Use `/imageframe` to inspect the available commands. A standard creation example is `/imageframe create mural <url> 2 2`. Replace the URL with a direct, accessible image link. Use a unique name so you can recognize the display later.

## Place the result

Follow the creation message and place the resulting map tiles in the intended order. **Empty maps are not required**. The default creation limit is **10 image maps per player**; permissions can grant a different limit. Image files must be at most **50 MiB**, and each map supports up to **20 markers**. Start with a small image before making a large wall.

## If loading fails

Check the URL, image type, size, and any allowed-source restrictions. A webpage containing an image is not always a direct image URL. Keep the error message when asking for help.

For shop stock displays rather than artwork, use [shelves in front of a chest](/docs/building/shelf-displays/).
