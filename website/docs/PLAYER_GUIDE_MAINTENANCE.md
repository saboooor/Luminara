# Player handbook maintenance

The public guides live in `src/routes/docs/`. They describe player tasks, not installation or server administration. Keep separate activities on separate pages; link between related guides rather than turning a system into one long reference page.

## Evidence and terminology

Reviewed October 17, 2026. The installed-component list establishes presence, not enabled options, permission grants, current configuration, or the running build's revision. Custom repository behavior was checked against its default branch at the time of writing. The server's configuration and live player interactions were not available.

User-confirmed terminology takes priority:

- Death storage is called **AngelChests**, even though the installed implementation is AxGraves. Keep that name in titles, navigation, and player prose. `/graves list` is the implementation's documented command, not an assertion that legacy `/actp` aliases exist or were removed.
- LumiView shows a chest's contents on shelves placed in front of that chest. The shelf guide uses this user-provided behavior. No commands, linking tool, display capacity, refresh timing, or supported-shelf list were invented.

The handbook distinguishes optional capabilities from confirmed server values. Prices, cooldowns, claim allowances, inventory-world groups, rank limits, fishing schedules, and feature permissions must follow the live menus or server configuration. Waystone and wrap recipes are identified as standard recipes, not verified overrides.

## Updating and checking

Each guide is an `index.md` with `title`, `description`, `keywords`, `date_created`, and `last_updated`. Search uses title, description, keywords, and route; put player vocabulary in descriptions and optional technical aliases in keywords. Keep public headings free of implementation names unless they are the in-game name.

Update the corresponding category overview when adding a guide. Every category with a breadcrumb has an actual landing page. Run `vp test`, `vp check` on changed files, and `vp run build`. The full repository check currently has pre-existing formatting failures in `src/components/sections/Ranks.tsx` and `src/global.css`; do not reformat unrelated files as part of a guide update.

Before asserting fixed server values, verify permissions as an ordinary player and inspect the running configuration. Particularly useful live checks are AngelChest aliases/expiry, banknote redemption, the installed armor-stand editor/rename controls, activity join/leave and inventories, voice-client compatibility, and custom-disc playback. These have not been represented as live-tested in this change.
