## Vote for Luminara

Open the [voting page](/vote/) and follow a voting site's instructions. Use your correct in-game name so eligible rewards can be associated with your account. Bedrock players should follow the site's instruction to include an **underscore before their gamertag**.

The voting page distinguishes reward-bearing buttons from blue buttons that only support the server. Voting on a support-only listing does not promise a reward.

## Understand rank benefits

The [ranks page](/ranks/) is the current reference for rank benefits. A command appearing in documentation does not mean every rank can use it. Check the benefit and any in-game restriction before planning around a higher limit.

For purchased packages, use the [store](/store/) and read what the package includes. Double-check the player account at checkout.

## If a reward does not arrive

Check the name you entered, whether that site offers rewards, and whether its voting cooldown had expired. Record the site and approximate vote time before asking for help. Avoid repeatedly voting or purchasing the same package to diagnose a delay.

Reward tag items have their own [redemption guide](/docs/social/tag-items/).
