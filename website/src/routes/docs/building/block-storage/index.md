## Open the Tome

A Tome stores eligible building blocks as **Echoes**. Open its menu and follow the controls shown for binding a material to a Page, depositing blocks, and withdrawing them. Only placeable block materials are eligible.

## Plan your Pages

Bind the materials you use most often, then check their stored counts. Capacity and progression determine what fits. In player-managed setups, upgrades unlock more storage; read the upgrade cost before spending resources.

Auto-deposit, when available, sends tracked pickups into storage. Check the count before assuming a pickup disappeared. World groups can have separate storage realms, so changing worlds can show a different ledger.

## Withdraw or place

Withdraw blocks when you need ordinary stacks. Placement mode can instead spend one stored Echo per successful placement. It still follows normal placement and land-protection rules.

Start with common blocks and a small test deposit so you recognize the menu's controls. Inspect counts before using broad inventory actions.

For group materials, see [shared Riftlinks](/docs/building/shared-materials/).
