## Reading worth values

These are the server worth values supplied for this reference, per single item. Multiply the unit value by the quantity for a reference total: 64 cobblestone at 0.3 each is 19.2; 64 bamboo at 0.001 each is 0.064 before any rounding.

Worth values are separate from prices chosen by players for shops and auctions. Check the actual transaction amount in game before selling; this table does not establish which selling commands your account can use. Items absent from the list have no value specified here.

## Comparing farm output

The supplied list identifies wither roses, slimeballs, string, iron ingots, spider eyes, bones, blaze rods, and cactus as farm outputs, and emeralds as obtainable through villager trades. A high output rate does not necessarily mean a high return: sugar cane and bamboo each have a unit worth of 0.001, and arrows are 0.0001.

Compare the amount you actually produce with the unit value, and follow server rules for farms. For other ways to earn money, see [jobs](/docs/economy/jobs/), [chest shops](/docs/economy/chest-shops/), and [auctions](/docs/economy/auction-selling/).
