Shelf displays let you see a chest's contents in the world. Place shelves **in front of the chest** to display what is stored inside.

## Set up a display

1. Choose the chest you want to display.
2. Place shelves in front of it.
3. Add items to the chest and check the shelf display.

Use this for a storeroom, a supply wall, or a shop's visual stock display. Arrange the area so you can still reach the chest and read any labels or shop signs.

## Storage, display, and sales

The chest is where you manage the stored items. The shelves provide the visual display. A shelf arrangement does not by itself create a shop or assign prices; use a [chest shop](/docs/economy/chest-shops/) for transactions.

Likewise, a visible item is not an access grant. Keep the chest protected with the appropriate [claim](/docs/protection/land-claims/) and [lock](/docs/protection/container-locks/).

## Check the arrangement

If contents are not showing, start with a simple chest-and-shelves arrangement and check that the shelves are in front of the intended chest. Record the block arrangement and which items you expected to see when asking for help. Do not empty or dismantle a valuable storage system merely to diagnose a display issue.
