## Open the Tome

A Tome stores eligible building blocks as **Echoes**. Open its menu and follow the controls shown for binding a material to a Page, depositing blocks, and withdrawing them. Only placeable block materials are eligible.

## Plan your Pages

Bind the materials you use most often, then check their stored counts. Luminara uses **player-selected Pages**, starting with **one Page** and capped at **18**. The per-material item limit is **unlimited** (`item-max: -1`). Netherite smithing upgrades are enabled and add **one Page**; diamond-block crafting upgrades are disabled.

Auto-deposit and placement are allowed in the default storage realm. No separate world realms are assigned, so the configured setup uses that default ledger. **Player heads and totems of undying are blacklisted** from Tome storage. Check counts before assuming an ordinary pickup disappeared.

## Withdraw or place

Withdraw blocks when you need ordinary stacks. Placement mode can instead spend one stored Echo per successful placement. It still follows normal placement and land-protection rules.

Start with common blocks and a small test deposit so you recognize the menu's controls. Inspect counts before using broad inventory actions.

For group materials, see [shared Riftlinks](/docs/building/shared-materials/).
