## Create or join a group

Where shared storage is available, `/tome riftlink create <name>` creates a Riftlink. Invite a teammate with `/tome riftlink invite <player>`; they accept with `/tome riftlink accept`.

Check `/tome riftlink info` and `/tome riftlink members` before depositing valuable materials. A shared ledger is intended for people you trust to use the group's resources.

## Build together

Members can work from shared Echoes when they have access to the relevant deposit and placement features. Agree on which supplies are communal and check the active ledger before using them.

## Manage membership

`/tome riftlink leave` leaves a group. Owners can use the available kick, rename, transfer, and disband actions. Read confirmations carefully and agree on ownership before transferring or disbanding the group.

For the underlying Pages, capacity, and placement behavior, see [Tome block storage](/docs/building/block-storage/).
